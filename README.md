# 🥟 ЧЕБУROOM Запоріжжя — Крафтовий Street Food

Сучасний сайт онлайн-замовлення та швидкого самовивозу крафтових чебуреків для закладу **ЧЕБУROOM** (Запоріжжя, пр. Соборний, 142).

## 🚀 Стек технологій
- **React 18** (Vite)
- **Tailwind CSS** (Світла та темна теми, Glovo & RnR естетика)
- **Lucide Icons**
- **Framer Motion** & **Canvas Confetti**

## 📦 Встановлення та запуск на іншому пристрої

1. **Клонувати репозиторій:**
```bash
git clone https://github.com/DmitriyKachan/cheburoom-zp.git
cd cheburoom-zp
```

2. **Встановити залежності:**
```bash
npm install
```

3. **Запустити сервер розробки:**
```bash
npm run dev
```
Сайт буде доступний за адресою: `http://localhost:3000`

4. **Збірка для продакшну (Production Build):**
```bash
npm run build
```
