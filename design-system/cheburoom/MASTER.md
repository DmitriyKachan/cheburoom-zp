## 2. Тематичні анімації Magic UI

1. **Magic Card (Spotlight Hover Glow):**
   - Розрахунок позиції курсору в межах кожної картки (`--mouse-x`, `--mouse-y`) для створення м'якого світлового променя над вітриною зі стравами.
2. **Border Beam:**
   - Плавний біжучий золотавий промінь по периметру картки *тільки* на фірмовому бестселері («Чебурек Класичний з яловичиною»), щоб природно фокусувати увагу.
3. **Craft Marquee:**
   - Безперервна горизонтальна стрічка маніфесту кухні між першим екраном та каталогом з паузою при наведенні.
4. **Interactive Hover Button:**
   - Кнопка з внутрішньою анімацією розширення точки та вильотом стрілки на ховері для ключових дій.
5. **Тактильний перемикач «Фритюр ⚡ Янтик»:**
   - Візуальне перемикання способу приготування безпосередньо в модальному вікні кастомізації страви.
